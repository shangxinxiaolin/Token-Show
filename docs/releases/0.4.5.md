## Token Show 0.4.5

### 新增

- 趋势图按模型堆叠：同一根柱子分段显示各模型的 Token、费用或请求量。
- 展示用量最高的 5 个模型，其余合并为「其他模型」；同名模型附服务商后缀。
- 概览、模型、会话、最近请求均跟随当前客户端与时间范围。

### 修复

- 修复快速连点指标或反复切换页面后图表空白（Chart.js 动画竞态）。
- 修复启动阶段切换客户端时旧响应覆盖界面的问题。
- 费用趋势按实际金额自动缩放；无费用或无用量的客户端显示明确提示。
